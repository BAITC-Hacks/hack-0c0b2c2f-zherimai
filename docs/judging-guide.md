# Проверка DalaAI: короткий маршрут

Инструмент отвечает на вопрос AML-аналитика: кого из 2 248 клиентов проверить первым и какие наблюдаемые данные это объясняют. Роли — гипотезы по переводам, без утверждений о виновности. Ниже только уже реализованные функции.

## 1. Получить результат из исходных данных

Подготовить Python и зависимости по [README](../README.md#быстрый-запуск). Затем из корня репозитория:

```bash
.venv/bin/python run.py --data data --out out
```

В Windows использовать `.\.venv\Scripts\python.exe`. Основной расчёт не требует ключа, GPU, внешнего API или сети после установки зависимостей. Фактическое время печатается в конце и записывается в `out/report.json`.

Ожидаются 2 248 строк в [nodes_roles.csv](../out/nodes_roles.csv), 49 групп в [clusters.csv](../out/clusters.csv), 50 строк очереди в [top_nodes.csv](../out/top_nodes.csv). Все 19 изолятов сохранены; на четвёртом колене нет terminal. Отдельная проверка: `.venv/bin/python validate.py`; независимая сверка по parquet: `.venv/bin/python scripts/audit_top.py`.

## 2. Открыть экран и проверить объяснение

Открыть локальный [out/network.html](../out/network.html) в браузере. В GitHub HTML может показываться как исходный текст — для работы нужен скачанный файл. Сначала открывается общий обзор без выбранного клиента. Нажмите «Первый в очереди» или найдите gid; идентификатор хранится строкой целиком.

| Пример для проверки | gid | Что видно по данным |
|---|---|---|
| Лидер очереди | `100000000331309100` | 5 плательщиков, 99 получателей, 11 структурных соседей. Coordinator по открытым порогам; структурно достижим от 7 seed, по совместимым датам — от 1. Это разные метрики, не доказательство происхождения средств. |
| Быстрый транзит | `100000000201868100` | Вход и выход по 190 000 KZT, ratio=1,0; не seed. Временное сопоставление 1–2 дня поддерживает гипотезу, но не идентифицирует те же деньги. |
| Обрыв выборки | `100000002622822100` | Depth=4, вход 750 000 KZT, видимого выхода нет. Peripheral: отсутствие исходящих на границе обхода не означает конечного получателя. |

Эти gid — примеры из рассчитанной таблицы, в алгоритмы они не встроены. Поиск принимает любой входной gid, включая изолят. В карточке доступны правило, фактические метрики, все сработавшие роли, пять слагаемых приоритета, ограничения, следующий запрос и кликабельные контрагенты.

Шаблон ответа на произвольный gid: **роль → два числа и порог → причина приоритета → ограничение и следующий запрос**. Репетиция команды с секундомером остаётся отдельной человеческой проверкой.

## 3. Оценить дополнительные функции и ограничения

- [Временные признаки и чувствительность](sensitivity-method.md): 5 seed Louvain и 11 вариантов весов; устойчивость не равна точности.
- [Сценарии удаления](../out/resilience.csv): после удаления топ-5 не-seed остаётся 204 из 391 достижимой пары seed→сборщик; это изменение структуры наблюдаемого графа.
- [Опциональный AI](ai-assistant.md): LLM выбирает один локальный инструмент, идентификаторы заменяются псевдонимами. Без ключа — явно обозначенные команды по правилам. [Живая оценка](ai-eval-results.json) содержит малый проверочный набор, не оценку точности AML-ролей.
