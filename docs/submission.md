# Текст и проверка технической подачи

## Название

DalaAI — Граф денег

## Описание

DalaAI помогает AML-аналитику выбрать, кого из 2 248 клиентов проверить первым и почему. Одна локальная команда преобразует исходные parquet в роли с формальными правилами, 49 групп, очередь из 50 узлов и автономный экран направленных переводов с поиском любого gid. Карточка показывает метрики, конкурирующие признаки, временную совместимость маршрутов, чувствительность результата и следующий запрос данных.

Решение учитывает обрыв на четвёртом колене, неполные входящие seed и отсутствие сведений о наличных, межбанковских и подпороговых переводах. Опциональный LLM выбирает разрешённый локальный инструмент графа; идентификаторы в запросе заменяются псевдонимами. Обязательный расчёт и интерфейс работают без API-ключей, GPU и интернета после подготовки зависимостей. Результаты описывают гипотезы для проверки, не устанавливают виновность.

Проверенное решение можно подать сейчас. **Инструкция участников, пункт 10, прямо разрешает обновлять решение до дедлайна хакатона.** По Положению 5.4.13–5.4.16 итоговая версия — срез репозитория на **18:00 23.09.2026 по Астане**. Подача сейчас не требует останавливать разработку до этого времени. Ориентир команды — не позже 17:30; push в GitHub не заменяет отдельную подачу.

1. Проверить выбранный кейс и правила формы: сохраняет ли она ссылку на репозиторий либо фиксирует конкретную версию/архив. Не предполагать, что после подачи можно незаметно заменить архив.
2. Заполнить название и описание, указать официальный репозиторий; при требовании дополнительных полей использовать фактические артефакты выше.
3. Нажать «Сдать решение» и проверить подтверждение платформы. Записать фактическое время и версию в TASKS.md, сохранить подтверждение.
4. При необходимых исправлениях до 18:00 отправить обновлённый код в тот же официальный репозиторий. Если форма сохраняет архив или явный commit, обновить и эти поля и повторно проверить подтверждение. Разрешение обновлять решение не означает, что загруженный архив заменяется автоматически. Не менять даты и авторство коммитов.

Статус этой записи: текст подготовлен; она **не подтверждает отправку формы**. Точная среда экспертов остаётся неизвестной; наличие Python и зависимостей необходимо подготовить по README.
