## Исправление по независимому QA

Ержан нашёл шесть обходов прежнего валидатора: подмены depth, is_seed или степени в CSV скрывали нарушение доменных правил. Ошибки текущих рассчитанных ролей он не обнаружил.

Теперь depth/is_seed сверяются с `nodes.parquet`; степени, суммы и число операций независимо собираются из `edges.parquet`. Для сумм допустима погрешность 0,01 KZT. Проверки depth=4, seed-транзита, изолятов, флагов и числа seed в кластере опираются на исходные данные. Дополнительно проверяются все строки node_stability/sensitivity, их диапазоны, сценарии и согласованность с основной таблицей.

Точные gid и изменения из переданного JSON Ержана повторены в временных копиях через прямой вызов `validate_outputs`: исходный результат PASS, **все 9 отрицательных сценариев отклонены**. Исходные data/out до и после одинаковы. Переносимый протокол с хешами: [validator-acceptance.json](validator-acceptance.json); регрессии: `tests/test_source_validation.py`.

## Чистое окружение и другая ОС

В отдельной папке macOS создан новый venv, закреплённые пакеты установлены из локальных wheels с `--no-index`: 14,68 с; `pip check` PASS. Первый прогон промежуточного объединения — 16,616 с по внешнему таймеру, 55 тестов и аудит PASS.

Затем финальные на тот момент исходники скопированы в новую папку **без out**, используя то же уже установленное чистое окружение. Ключ API и PYTHONPATH удалены из окружения процесса. Расчёт — **4,354 с** по внешнему таймеру (4,1737 с внутри); отдельный валидатор, 67 тестов и независимый аудит PASS. Все 7 CSV и HTML побайтно совпали с рабочим результатом. Разница числа тестов объясняется последующим слиянием 23 тестов помощника; полный набор после него — 90/90. Повторная установка зависимостей не выполнялась и не заявляется.

После последнего слияния помощника и браузерного исправления проверка повторена из ещё одной новой папки без out: **4,910 с** по внешнему таймеру; отдельный валидатор, **90 тестов**, независимый аудит и переносимый DOM-тест PASS. Семь CSV и итоговый HTML побайтно совпали с рабочим деревом. Это окончательная проверка описанного здесь объединения; использовано то же чистое окружение, без повторной установки. Краткий машинный протокол с хешами файлов: [verification-integration.json](verification-integration.json).

Ержан независимо проверил `cc2c0b0` на Windows 11 AMD64/Python 3.13.15 с ранее установленными закреплёнными пакетами: расчёты без сохранённого out — 3,4308/3,6406 с; 49 тестов и аудит PASS. Все 7 CSV и HTML повторяются побайтно внутри Windows. SHA-256 всех семи CSV macOS после преобразования LF→CRLF совпали с записанными Ержаном Windows SHA-256: различие между ОС только в окончаниях строк. Это проверено отдельно интегратором, а не выведено из похожего количества строк. Отчёт: [QA Ержана](handoffs/qa-erzhan-20260923.md).
