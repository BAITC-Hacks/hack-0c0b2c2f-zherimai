# Модули для трёх участников

Группы ниже — передача файлов для проверки и реального вклада. Не меняйте автора коммита и не приписывайте себе чужую проверку. Перед каждым коммитом проверьте `git diff --cached`, чтобы не захватить чужие изменения. Время и историю не переписывайте.

## A — данные и расчёт

Файлы: `aml/__init__.py`, `load.py`, `features.py`, `roles.py`, `clusters.py`, `priority.py`, `explain.py`, `resilience.py`, `scripts/analyze.py`, `docs/analysis.md`, `docs/analysis.json`, `requirements.txt`, `.gitignore`, `.env.example`.

Проверка: прочитать формулы, сверить несколько узлов со входными parquet. `data/` и оригинальный `starter/` включать в официальный репозиторий с разрешённым доступом в рамках хакатона; лицензию описывает README.

## B — экран

Файлы: `aml/viewer.py`, `aml/viewer_template.html`.

Проверка: после полного прогона открыть `out/network.html`, найти произвольные gid из CSV, в том числе изолят и узел глубины 4; проверить стрелки, соседей, фильтры и карточку. `gid` хранится строкой, а не JavaScript Number.

## C — интеграция, проверка и объяснение

Файлы: `run.py`, `validate.py`, `aml/validate.py`, `aml/assistant.py`, `tests/`, `README.md`, `AGENTS.md`, `TASKS.md`, `docs/compliance.md`, `docs/demo.md`, `docs/architecture.svg`.

После объединения: выполнить команды README и включить свежие `out/` в итоговый коммит. Проверить вклад/источники, выполнить push до 18:00 и отдельно сдать кейс на платформе. Только последний шаг завершает подачу.

Части взаимозависимы: один модуль сам по себе не запускает приложение. Готовый полный набор файлов сейчас лежит в этом репозитории; перед разделением коммитов согласуйте границы между участниками.
