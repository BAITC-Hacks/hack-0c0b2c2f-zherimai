# DalaAI: демо на 5 минут

Перед выходом: запустить финальную команду из README в чистой папке, убедиться в наличии CSV и автономного экрана. Выбрать примеры из текущего результата: один приоритетный не-seed, один транзитный или распределяющий узел и один узел 4-го колена. Если роль не обнаружена, выбрать существующую и честно объяснить. Не вшивать примеры в алгоритм.

## Ответ на три произвольных gid за минуту

На каждый узел примерно 20 секунд: поиск → фактические метрики → сработавшее правило и порог → причина приоритета → существенное ограничение. Для peripheral: отсутствие выполненных критериев, а не «безопасный клиент». Для seed: известен заранее, его вход наблюдается неполно. Для coordinator: структурный кандидат для проверки, не установленный организатор.

## Шпаргалка защиты

- «Почему эти пороги?» — показать распределения и зафиксированные правила README; нет ground truth, пороги объясняют наблюдаемое поведение.
- «Это те же деньги?» — нет идентификации денежных единиц и начальных остатков; временная близость лишь усиливает гипотезу.
- «Почему столько кластеров?» — описать проекцию, веса, seed и отдельную обработку изолятов; число кластеров не подгоняется под подсказку.
- «Где AI?» — опциональный LLM переводит вопрос аналитика в один разрешённый запрос к графу: карточку, путь, общих получателей или кластер. Gid заменяются псевдонимами, инструмент выполняется локально, ответ ссылается на рассчитанные данные. 12/12 подготовленных случаев живой оценки прошли; это небольшой набор разработки. Классификация ролей остаётся объяснимой, а без ключа доступен честно обозначенный режим по правилам.
- «Почему у лидера 7 seed, а по датам только 1?» — 7 означает структурную достижимость без дат; 1 — совместимость маршрута с наблюдаемыми датами. Приоритет — очередь структурной проверки, не доказательство движения денег от семи seed. Разницу показываем прямо в карточке; запросим недостающие периоды, входящие и остатки.
- «Повторим на другой машине?» — открыть README и выполнить ту же команду без личного аккаунта, облака и обязательных ключей.
- «Что изменится на миллионе узлов?» — сослаться на конкретный раздел README; не заявлять, что этот масштаб уже протестирован.

Если показ запуска занимает больше запланированного времени, продолжать по последним успешно проверенным артефактам, явно сказав, что они созданы предыдущим запуском этой же версии. Не выдавать подготовленные результаты за завершившийся живой прогон.
