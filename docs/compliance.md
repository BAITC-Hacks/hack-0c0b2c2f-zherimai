## Обязательные результаты кейса

| Требование | Проверка |
|---|---|
| Один запуск от трёх parquet до трёх CSV | Команда README без ручного редактирования; менее 5 минут |
| Роль и скор всех 2 248 узлов | Обязательные поля заполнены, role_score и priority_score в [0,1], evidence непустой, с числами, до 200 символов |
| Объяснимые роли | Для каждой роли правило и порог; три названных жюри gid объясняются за минуту |
| Кластеры каждого узла | Размер, число seed, внутренний оборот, top_gids и гипотеза в `clusters.csv` |
| Не менее 20 приоритетов и экран | Ранжирование с why; направление потоков, роли/кластеры, поиск любого gid и его связи |
| README и схема | Одна команда; критерии/пороги; выходы; ограничения; масштабирование до ~1 млн узлов; схема «данные → метрики → роли → интерфейс» |
| Пятиминутное демо | Живой запуск и разбор 2–3 реальных узлов из результата |

Словарь: consolidator, transit, distributor, terminal, coordinator, peripheral. Расширение допустимо с документацией. Дополнительные колонки CSV разрешены README стартера; обязательные удалять нельзя. Нет разметки ролей: нельзя заявлять измеренную accuracy или калиброванную вероятность.

## Ограничения интерпретации

- 4-е колено обрезано; отсутствие исходящих не доказывает конечного получателя.
- Входящие seed неполны; отношение выхода к входу не равно полной картине движения средств.
- Суммы выше наблюдаемого входа могут объясняться начальным остатком или невидимыми потоками; не объявлять внешнее пополнение доказанным.
- Нет переводов ниже 5 000 KZT, межбанковских операций, наличных и остатков. Не восстанавливать их вымышленными числами.
- Все выводы — гипотезы для проверки; атрибуты клиентов и внешнее обогащение запрещены. Данные лицензированы только для использования в рамках хакатона.
- Внешний LLM API ТЗ допускает опционально; он не должен быть необходим для воспроизведения обязательного результата.
- Заявленные в ТЗ 16 слабосвязных компонент и 352 узла вне крупнейшей компоненты требуют оговорки: 2 248 − 1 877 = 371. Разница 19 совпадает с числом seed без рёбер. В отчёте приводить рассчитанные значения отдельно для полного графа и графа с рёбрами.
- Подсказка о 8 Louvain-сообществах не является целевым количеством всех кластеров и не оправдывает подгонку результата.
