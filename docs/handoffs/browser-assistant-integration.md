# Строгие команды браузерного помощника

Задача / исполнитель: агент капитана, интеграция после уточнения CLI-помощника Ержаном.
Ветка и commit: рабочая `main`, без отдельного коммита; передано интегратору.
Изменённые файлы: функция `assistant()` и её подсказки в `aml/viewer_template.html`; эта запись. Общие документы, расчёты и отслеживаемые `out/` не менялись.

Исправлен дефект: раньше любой известный gid в произвольном вопросе молча превращался в ответ-карточку; неизвестные gid и часть списка могли игнорироваться. Теперь принимается полная команда: «топ», «кластеры», «ограничения», полный gid либо «Объясни <gid>». Регистр и завершающие `.?!` допустимы. Список до трёх разных gid принимается с разделителями пробел, запятая, точка с запятой или «и». Повторы дедуплицируются; превышение лимита явно отклоняется целиком. Все переданные полные gid проверяются до выдачи ответа; при неизвестном gid весь запрос отклоняется с его указанием. Произвольный вопрос и неполная команда показывают справку. Ошибка/справка не меняют выбранный узел, его карточку и режим карты. Paths, common receivers, API и дополнительные возможности не добавлялись.

Проверено самостоятельно на macOS, Python 3.13.2, Node 22.14.0: HTML пересобран через `build_viewer` из нынешних `out/` в `out-check/ui-integration/network.html`. DOM-проверка `node out-check/ui-integration/check.cjs` прошла: прежние пять карточек/скачивание/метрики/изоляты/поиск/фильтры; 17 неподдержанных и неполных запросов; 6 неизвестных и смешанных gid; превышение лимита. Для всех негативных случаев подтверждено сохранение карточки, выбора, режима и видимого графа. Восемь вариантов команд gid и четыре команды сводки работают; кнопки gid в ответах переходят к нужному узлу. `git diff --check` — PASS.

Ограничение: это DOM-заглушка, не визуальная проверка браузером. Для завершения интегратору пересоздать `out/network.html`, затем человеку просмотреть актуальный экран.
