# Интеграция новых показателей в карточку

Задача / исполнитель: агент капитана, узкая интеграция после получения UI Александра. Авторство исходного UI-коммита сохранено интегратором.

Ветка и commit: рабочая `main`; изменения переданы интегратору без отдельного коммита.

Изменённые файлы: `aml/viewer_template.html`, эта запись. `aml/viewer.py`, вычисления, README и отслеживаемые `out/` не менялись.

Что изменилось для аналитика:

- Сохранены состав приоритета из пяти рассчитанных вкладов, множитель seed, базовая роль и четыре знака точности из работы Александра.
- Карточка и скачиваемый текст показывают все `matched_roles` и точный `next_request` из расчёта.
- `seed_reach` явно назван структурной связью без дат. Отдельно показаны `temporal_seed_reach_strict_days` и `temporal_seed_reach_upper`: строго возрастающие дни и оптимистическая граница с возможным порядком внутри дня. Ни один показатель не прослеживает происхождение средств; приоритет остаётся структурным.
- Добавлены средний Jaccard состава сообщества, доля попаданий в топ-20 и диапазон мест при вариациях весов. Для `isolate_not_assessed` показано «Не оценивалась», техническая единица не отображается как измеренная устойчивость.
- Подписи объясняют четыре альтернативных разбиения и 11 вариантов весов; никаких новых оценок UI не вычисляет, только форматирует сохранённые значения.

Проверки: macOS, Python 3.13.2, Node 22.14.0. `build_viewer` собрал текущие данные в `out-check/ui-integration/network.html`. JavaScript успешно разобран и исполнен в Node с DOM-заглушкой. Проверены пять карточек и скачиваемых текстов (лидер, изолят, depth=4, transit, seed с выходом), точное соответствие дат/мест/частот данным, полный gid строкой, следующий запрос, сохранённые вклады и скидка seed, отсутствие утверждения об устойчивости изолята. Поиск неизвестного gid оставляет предыдущий выбор; два шага и фильтр transit работают. Проверка — `node out-check/ui-integration/check.cjs`; PASS. Вспомогательная заглушка находится в игнорируемом `out-check/` и не является браузером.

Не проверено: визуальная компоновка обновлённой карточки в настоящем браузере. Ранее явный запрет инструмента на локальный файл не обходился. DOM-проверка не заменяет человеческий просмотр.
