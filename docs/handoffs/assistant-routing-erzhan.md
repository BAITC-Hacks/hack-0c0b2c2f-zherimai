# Передача C: явные команды локального помощника

23.09.2026. Участник — Erzhan и Codex. Ветка `codex/qa-erzhan`, основана на `cc2c0b0`; предыдущий QA-отчёт — `108e2a4`.

## Что изменилось для аналитика

Ранее любой вопрос с gid мог вернуть карточку, даже если пользователь спрашивал о недоступном доходе. Запрос пути с одним gid также превращался в карточку, а запрос с тремя gid молча использовал первые два. Теперь помощник проверяет полную поддерживаемую команду и объясняет неподдерживаемый запрос или неверные аргументы.

Примеры поведения:

| Запрос | Ответ |
|---|---|
| `Объясни <gid>` или отдельный gid | Карточка известного узла либо ошибка неизвестного gid |
| `Какой доход у клиента <gid>?` | Справка о поддерживаемых командах; карточка не подменяет ответ о доходе |
| `Путь от <gid>` | Пояснение, что требуются ровно два gid |
| Путь с тремя gid | Ошибка аргументов; первые два автоматически не выбираются |
| `Общие получатели <gid>` | Пояснение о минимум двух разных gid |
| `Кластер -1`, `Кластер 1.5`, `Кластер 1abc` | Ошибка формата; номер не обрезается до другого положительного кластера |

Документированные четыре команды сохранены. Поддерживаются русские/английские формы `Объясни` / `explain` / `node`, `Путь от ... до ...` / `path from ... to ...`, `Общие получатели` / `common receivers`, `Кластер` / `cluster`; конечная точка, вопросительный/восклицательный знак и внешние пробелы допустимы. Список gid можно разделять пробелами, запятыми, точкой с запятой, `и` / `and`.

Gid обрабатываются как непрерывные ASCII-цифры длиной 15–20 символов, без округления и Unicode-нормализации. Неподдерживаемые свободные формулировки получают справку. Это намеренное ограничение локального детерминированного режима; понимание произвольного языка не заявляется.

## Изменённые файлы

- `aml/assistant.py`: только маршрутизация `answer` и её константы; методы чтения графа/метрик сохранены.
- `tests/test_assistant.py`: 23 контрактных теста на небольшом синтетическом графе с точными строковыми gid; не зависят от сохранённого out.
- Этот отчёт.

Интерфейс ответа `{mode, tool, result}` сохранён. Неизвестный gid по-прежнему возвращается с ошибкой внутри списка `get_node`; неправильные аргументы инструментов — с `result.error`. `aml.ai_assistant` и его онлайн-планировщик не менялись. Методы, которые онлайн-планировщик вызывает напрямую, также не менялись.

## Проверки и фактические результаты

Среда: Windows 11 AMD64, CPython 3.13.15, ранее установленный `out-check/qa-env` с закреплёнными зависимостями.

- **72/72 unittest прошли**, включая 23 новых и прежние 49; 1,642 с по unittest, с `ResourceWarning` как ошибкой. Набор выполнен вне песочницы инструмента для работы штатных TemporaryDirectory.
- Независимая проверка: **30 локальных сценариев** и **6 сценариев реального AI-помощника с online=False** прошли. Проверены в том числе неподдерживаемый вопрос с gid, неполный путь, неизвестный gid с точкой, Unicode-цифры и лишний текст. HTTP-вызовов 0, журнал квоты не создавался.
- Полный расчёт от реальных parquet: PASS, **3,4698 с** по отчёту; **3,6658 с** по внешнему таймеру процесса.
- Все **7 CSV и HTML побайтно совпали** с результатами проверенного main `cc2c0b0`. Роли, scores, кластеры и основная очередь этим изменением не меняются.
- `git diff --check` проходит.

Команды из рабочего дерева ветки, где `$qaPython` — путь к установленному Python 3.13.15:

```powershell
& $qaPython -B -W error::ResourceWarning -m unittest discover -s tests -v
& $qaPython run.py --data data --out out-check/assistant-fix/result
& $qaPython -m aml.assistant --data data --out out-check/assistant-fix/result --question 'Путь от <gid>'
```

В последнем примере заменить `<gid>` любым gid из результата. Локальные подробные протоколы сохраняются в игнорируемых `out-check/assistant-fix/` и `out-check/assistant-review/` внутри рабочего дерева QA.

## Ограничения и следующий шаг

Браузерный помощник в HTML — отдельная реализация B и этим изменением не исправляется. Реальные платные API-вызовы не повторялись. Свободный текст, который раньше случайно приводил к карточке, теперь получает справку; это не семантический классификатор вопросов.

Интегратору: принять изменение `aml/assistant.py` вместе с `tests/test_assistant.py`, затем повторить общий набор тестов на объединённой версии. Владельцы валидатора и UI продолжают свои изменения; C не изменял их файлы. Приёмка девяти отрицательных сценариев валидатора остаётся отдельной задачей после публикации его исправления.
