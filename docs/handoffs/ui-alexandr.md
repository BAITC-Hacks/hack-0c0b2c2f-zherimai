- Для топ-20 проверены выполнение минимального правила роли и сумма пяти сохранённых вкладов приоритета; все 20 совпали.
- Browser Use отклонил открытие нового локального HTML по политике `file://`. Визуальный просмотр именно обновлённой карточки в настоящем браузере не подтверждён.
